## 3. Discovered Vulnerabilities & Quality Areas to Improve

### Critical Improvements for Large Scale Public Adoption:
1. **IP Rate Limiting on Registration:**
   - **Risk:** 10 registrations/hour per IP will immediately block users on Indian mobile networks (Jio, Airtel) using CGNAT.
   - **Remediation:** Replace strict IP counting with Cloudflare Turnstile / hCaptcha or progressive backoff.
2. **Phone Number Collision Handling:**
   - **Risk:** Unverified phone numbers with a hard UNIQUE constraint can cause user lockout if someone enters a wrong number.
   - **Remediation:** Introduce SMS OTP verification before marking phone numbers as permanent identifiers.
3. **API Message Property Asymmetry:**
   - **Finding:** Initial enquiry uses `message` while thread replies require `body`.
   - **Remediation:** Support both `body` and `message` aliases in `replyEnquiry`.
4. **Real-Time Communication (Replace Polling):**
   - **Finding:** 15s polling drains mobile battery.
   - **Remediation:** Introduce Server-Sent Events (SSE) or WebSockets via Redis pub/sub.
5. **Background Image Transcoding:**
   - **Finding:** Synchronous image processing during upload can degrade API throughput under heavy traffic.
   - **Remediation:** Upload original to storage and enqueue a background resizing job in `jobs`.
